# public/docs — 配布資料PDFの置き場

資料セクション（トップページ「資料ダウンロード」）から参照される PDF をここに置きます。
`src/data/resources.ts` の `file` 名と一致させてください。

| 置くファイル名 | 元ファイル |
|---|---|
| `where-service-approachbook.pdf` | WHERE_APB_20260702_商談用_v2.2.1.pdf（Approach Book） |
| `where-service-onepager.pdf` | WHERE_ペライチ資料.pdf（サービス概要） |
| `where-service-compact.pdf` | WHEREご紹介資料_コンパクト版.pdf |

配置後に push すると、GitHub Pages 上で
`/where-partner-portal/docs/<ファイル名>` として配信されます。
差し替え時は同名で上書きしてください。
